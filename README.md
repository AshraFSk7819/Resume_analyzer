# AI Resume Analyzer

An AI-powered web application that analyzes a candidate's resume against a job description and produces a structured match analysis.

## Features

- Upload a resume in PDF format
- Paste a job description
- Extract structured information from the job description
- Extract candidate information and skills from the resume
- Identify matching skills
- Identify missing important skills
- Check whether the experience requirement is met
- Generate an overall match score
- Generate a recruiter-style final verdict

## Tech Stack

- Python
- Streamlit
- Groq API
- OpenAI GPT-OSS 20B
- Pydantic
- PyMuPDF
- uv

## How It Works

The application follows three main stages:

1. **Job Description Analysis**
   - The pasted job description is sent to the LLM.
   - Important job requirements are extracted into a structured `JobD` model.

2. **Resume Analysis**
   - The uploaded PDF is processed with PyMuPDF.
   - Resume text is sent to the LLM.
   - Candidate information is extracted into a structured `Resume` model.

3. **Candidate Matching**
   - The structured job description and resume are compared.
   - The application returns a match score, matching skills, missing skills, experience evaluation, and a final verdict.

```text

       |

                  |

```

## Setup

### 1. Clone the repository

```bash
git clone https://github.com/AshraFSk7819/Resume_analyzer.git
cd Resume_analyzer
```

### 2. Install dependencies

This project uses `uv`.

```bash
uv sync
```

### 3. Configure the API key

Create a `.env` file in the project root:

```env
GROQ_API_KEY=your_groq_api_key_here
```

Do not commit `.env` to GitHub.

### 4. Run the application

```bash
uv run streamlit run app.py
```

The application will open in your browser.

## Usage

1. Paste a job description into the Job Description field.
2. Upload a resume in PDF format.
3. Click **Analyze Resume**.
4. Review the generated analysis.

The results include:

- Overall match percentage
- Candidate name
- Matching skills
- Missing important skills
- Experience requirement status
- Final recruiter-style verdict

## Current Limitations

- Match scoring is currently generated by the LLM.
- Skill matching is based on the model's interpretation.
- Only PDF resumes are currently supported.
- Results depend on the quality of the supplied resume and job description.
